# Campagne de Marketing Viral : Opération Lupin

> **⚠️ AVERTISSEMENT LÉGAL ET ÉTHIQUE :** Ce projet est un travail strictement étudiant réalisé dans le cadre d'un exercice de communication au BUT Informatique. Il s'agit d'une simulation de campagne de marketing viral utilisant les techniques de l'ingénierie sociale et des "Fake News". Le site, les articles et les vidéos (braquage) sont intégralement fictifs. Ce projet n'a aucune affiliation avec *Le Parisien*, *Netflix*, *TF1* ou l'acteur Omar Sy.

## Présentation du Projet
Ce dépôt contient le code source et les médias d'une fausse page web d'actualité. L'objectif de cet exercice de communication était d'effacer la frontière entre la fiction et la réalité (technique du "Blurring") pour faire la promotion de la série *Lupin*. 

Le concept : simuler un véritable braquage au musée du Louvre orchestré par l'acteur principal lui-même, en reprenant l'identité visuelle d'un grand média national.

## Aspect Technique
Le projet a été entièrement codé et intégré "from scratch" en utilisant les technologies web de base :
* **HTML / CSS** : Reproduction de l'interface, du header et de la structure des articles.
* **Intégration Vidéo** : Intégration de fausses vidéos de surveillance (`Vol.mp4`).
* **Hébergement** : Déploiement continu via GitHub Pages.

## Contenu du dépôt
Contrairement à une application classique, ce dépôt est structuré comme un site web statique direct :
* `index.html` : La page d'accueil principale (le faux article).
* `betisier.html` : Une page "Making-of" dévoilant les coulisses du projet.
* Fichiers `.mp4` et `.jpg` : Les ressources médias (vidéo du braquage simulé, bêtisier, fausse Une de journal).
